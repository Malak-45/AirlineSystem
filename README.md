✈️ Airline Reservation & Booking System | C++

I developed a console-based Airline Reservation & Booking System using C++ to simulate the core operations of a real-world airline booking process.

✨ Key Features:
• ✈️ View available flights
• 🔎 Search for a specific flight
• 🎫 Book flights and generate a unique Booking ID
• 👤 Store passenger information
• 💺 Manage available seats and prevent overbooking
• 💰 Calculate the total booking price
• 🔍 Search and view booking details
• ❌ Cancel bookings and restore available seats
• 📋 View all active bookings
• ⚠️ Handle invalid inputs and unavailable flights/seats

🛠️ Technologies & Concepts:
C++ | Arrays | Loops | Conditions | Strings | User Input | Functions & Logic | Data Management | Problem Solving

💡 This project helped me practice designing real-world business logic and converting an airline reservation workflow into a functional C++ application — while strengthening my programming fundamentals before moving into OOP.
